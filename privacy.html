Privacy policy - blur updates

blur updates is a personal command-line tool, used only by its owner, that uploads the owner's own videos to the owner's own YouTube channel.

YouTube API Services

blur updates uses YouTube API Services. By using it you are also bound by the Google Privacy Policy.

What data is accessed, used, stored and shared

The tool requests the YouTube upload permission (OAuth 2.0) and only calls the videos.insert endpoint to upload a video file chosen by the user, with a title and privacy status. It does not read any other YouTube or Google account data.

The OAuth access token is stored only in a local file on the user's own computer. No data is sent to any server other than Google's, and no data is shared with third parties, sold, or used for advertising.

Revoking access and deleting data

You can revoke the tool's access at any time from the Google security settings page. Deleting the local token file also removes all stored data. Uploaded videos can be deleted in YouTube Studio.
